### Chat-first agents and a shared inbox

The console's Agents page now opens a chat built from the shared `agent-chat` registry component. Chats stream replies, show tools and workers, accept human input inline, and support attachments, queued messages, steering and stopping. Older messages load above the conversation. Agent controls, files, requests and schedules are under Manage agent.

Agents show conversation previews and pending-input counts. The new Inbox lists pending questions, decisions and approvals across agents, with priority and type filters and keyboard navigation. Inbox answers use the existing per-agent input routes.
