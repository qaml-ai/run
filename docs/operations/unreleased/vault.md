### Vault credentials and limited Workers networking

Tenant and workspace vault APIs store write-only credentials under the existing secrets key. Workers computers can substitute attached placeholders at HTTPS egress; remote tool sources can reference vault credentials. `networking` limits Workers computer destinations. Node/Sprites refuses limited networking. See `docs/guides/vault.md`.

Inline children inherit the parent’s network policy, secrets and grants; definition children and existing delegation targets keep their own. GitHub App git traffic streams without response masking; vault masking also covers untyped, octet-stream and JavaScript responses. Known binary responses bypass masking. Masked streams omit fixed lengths and validators. Body substitution requires `inBody: true`, while header-only requests stream without a body cap. Reserved runtime environment names and values shorter than eight characters are refused. `scripts/verify-egress.mjs` checks clone/push, vault substitution and blocked hosts on a pilot parent, fork and inline child, cleaning up its scratch branches and agents.
