### Budget pauses, mount instructions and unattended approvals

Spend-limit results report `paused` and `budget_reached`; SDK runs return them without throwing. Legacy spend-limit fields remain. Mounts accept instructions up to 4,096 characters. Delegate targets can pin a saved definition revision, and maxParallel accepts up to 64 under existing capacity limits. `humanInput.unattended: "decline"` declines approval requests immediately.
