### Budget pauses, mount instructions and unattended approvals

Persistent spend-limit results report `paused` and `budget_reached`; SDK runs return them without throwing. Stateless runs report `failed`, since they cannot resume; the CLI exits nonzero for budget pauses. Legacy spend-limit fields remain. Mounts accept instructions up to 4,096 characters each and 8,192 total, framed as notes from the owner. Delegate targets can pin a saved definition revision, and maxParallel accepts up to 64 under existing capacity limits. Workers use child-to-parent notifications and one five-second recovery sweep, with at most six fallback reads in flight and no per-child relay streams. `humanInput.unattended: "decline"` declines approval requests immediately; questions still wait. Rotating or removing credentials purges their sealed values from old definition revisions.

Workers keep child tasks and results outside status rows, read payloads and notification outboxes without the storage cache, and share the background wait. Child transcript events no longer rebuild the parent turn snapshot. Above 32 running children, `delegation_memory` logs the child count and an estimate of parent delegation bookkeeping bytes (not total isolate memory).
