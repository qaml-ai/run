# Security policy

## Reporting a vulnerability

Please report security issues privately, not in public issues or pull requests:

- **GitHub:** use [Report a vulnerability](https://github.com/qaml-ai/run/security/advisories/new) on this repository's Security tab.
- **Email:** support@camelai.com with "Security" in the subject.

Include what you found, how to reproduce it, and its impact. We'll acknowledge your report, keep you updated while we fix it, and credit you in the advisory if you'd like.

## Scope

This repository (the runtime, SDKs, CLI and packages) and the hosted service at agents.camelai.dev. Please don't access other people's data, degrade the service, or run automated scans against the hosted service.
